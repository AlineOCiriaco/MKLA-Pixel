# 🚀 Desafio de 30 Dias Programando

**Objetivo:** sair do zero explorando Web, Python e Dados, criar projetos reais no GitHub e documentar o aprendizado no LinkedIn.

**Regras:**
- ✅ Commit no GitHub todo dia (mesmo que pequeno)
- ✅ Cada projeto = 1 repositório com README explicando o que foi feito
- ✅ Ao fim de cada semana, um post curto no LinkedIn resumindo o aprendizado
- ⏱️ Meta: 30-60 min por dia

---
